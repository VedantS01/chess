# chesslab

Chess engine wrapper, bot framework, RL training, and an online platform — built on top of [`python-chess`](https://github.com/niklasf/python-chess).

> **Status**: under active development. See `/root/.claude/plans/set-up-a-fully-refactored-dongarra.md` for the build plan.

## Quickstart (offline)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[rl,dev]"
chesslab version
```

More documentation lands as later build steps complete.
